# Muhammad Faisal Jahangir — Portfolio

A modern, responsive portfolio for Muhammad Faisal Jahangir, Senior Frontend Developer.

## Run locally

Open `index.html` directly, or start any static server in this directory.

```bash
npx serve .
```

## Deploy with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the `main` branch at `/ (root)`.

## Structure

- `index.html` — content and semantic page structure
- `styles.css` — responsive visual system and animations
- `script.js` — mobile navigation, scroll reveals, and smooth navigation
